## How to see whether something works

Nothing here needs credentials, a network or a browser profile. Every one of these
runs against the committed synthetic Sunday.

```bash
python3 -m pytest                              # 199 tests, offline
python3 -m app                                 # http://127.0.0.1:8011
python3 tools/replay_check.py --speed 1800     # watch the scores move
python3 tools/timeline.py                      # every Moment of the day
python3 tools/transcript.py --stats            # what the commentary would say, and how often it repeats
python3 tools/recap.py                         # the weekly write-up
python3 tools/phrase_lint.py                   # dead triggers, unfillable slots, thin categories
python3 tools/a11y.py                          # contrast
python3 tools/screenshot.py                    # captures at a real phone width
python3 tools/screenshot.py --check-overflow   # horizontal overflow at 390px
```

**Look at the screenshots.** Six separate defects in this repository were invisible in
the code and obvious in a capture: truncated team names, a demo opening on ten zeros, an
HTML entity rendered literally, a sealed pack over a screen-high void, the TV type at
phone size, and every "IN" chip the wrong colour. The code read fine each time.

## Hard rules

1. **One gunicorn worker.** The live feed's poller, the event engine's dedupe set and the
   Moment buffer are per-process. A second worker polls ESPN twice and gives half the room
   a different commentary feed. `tests/test_deploy_config.py` enforces it.
2. **gthread, not sync workers.** An SSE connection is held open all afternoon; ten phones
   on `/stream` would occupy every sync worker permanently.
3. **Never commit a real recording.** `data/recordings/` tracks only `demo-*`. A capture of
   the real league carries ten people's ESPN display names and account GUIDs, and this
   repository is public. The fixture is generated by `tools/make_fixture.py`.
4. **Regenerate the golden timeline deliberately** (`python3 -m tests.golden_regen`) and read
   the diff. It is the record of what the engine does to a whole Sunday.
5. **Never put an HTML entity in a view model.** They are text; Jinja escapes them, and
   `A &mdash; B` reaches the page as those literal characters. Guarded by a test.
6. **Bus levels are arithmetic, not taste.** Web Audio hard-clips; all four buses ducked
   under a play call must sum to 1.0 or less, and commentary must stay above stings above
   music. Both are tests, because satisfying one while breaking the other is easy.
7. **Every sound is synthesised** by `tools/make_audio.py`. Nothing is sampled or downloaded,
   which is why `static/audio/LICENCES.md` cannot drift.
8. **The recap validator is not optional.** Every numeral and proper noun in generated prose
   must appear in the fact pack. A recap that invents a score is worse than none, because
   the league will believe it.
9. **Port 8011.** 8000 to 8010 belong to the other apps on the droplet.

## Things that cost an hour each, once

- **iCloud makes conflict copies.** This repository is under a synced `Documents` folder, so
  rewriting a directory in place resurrects the previous generation as `<stem> 2.<ext>`.
  Ninety-nine reached the first commit. `.gitignore` excludes them, `make_fixture.py --check`
  sweeps them, and the test asserts against the git index rather than the working tree,
  because new ones appear at any moment.
- **Chrome will not give a window narrower than 500px on macOS**, so `--window-size=390`
  silently lays out at 500 and captures a crop. `tools/screenshot.py` renders into a
  correctly sized iframe instead.
- **`--virtual-time-budget` never settles with an infinite CSS animation running**, so any
  headless probe using it hangs the moment a looping animation lands on the page.
- **Chrome's HTTP cache persists across headless launches**, so a regenerated harness at the
  same URL serves the previous run's contents.
- **A fresh `--user-data-dir` hangs Chrome outright** on this machine.
- **Desktop Chrome ships `DeviceOrientationEvent.requestPermission`**, so the usual "that
  means iOS" recipe is wrong. Gate on `(hover: none) and (pointer: coarse)`.
- **`str.replace` on a short CSS anchor matches twice.** `.verdict {` hit both the base rule
  and `.cheer--conflicted .verdict`, duplicating a block and silently changing a colour.
  There is a duplicate-selector test now.

## Style

Comments explain **why**, and especially why an obvious alternative is wrong. A comment
that restates the code is noise; one that records a measurement, a failed approach or a
platform quirk is the most valuable thing in the file. Several of the rules above exist
only because the comment beside the code said what went wrong.

British English. No em dashes.
