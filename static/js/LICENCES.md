# Third-party assets in `static/`

Every vendored file needs a line here. No exceptions, no orphan files.

| File | Source | Version | Licence |
|---|---|---|---|
| `js/htmx.min.js` | [htmx.org](https://htmx.org) via unpkg | 2.0.4 | [BSD 2-Clause](https://github.com/bigskysoftware/htmx/blob/master/LICENSE) |
| `js/howler.min.js` | [howlerjs.com](https://howlerjs.com) via cdnjs | 2.2.4 | [MIT](https://github.com/goldfire/howler.js/blob/master/LICENSE.md) |

| `../fonts/*.woff2` | Google Fonts | Anton v27, Inter, Roboto Mono | [SIL Open Font Licence 1.1](https://openfontlicense.org) |

Everything else in this directory (`app.js`, `audio.js`, `board.js`, `cards.js`,
`countdown.js`, `identity.js`, `sheet.js`, `sw.js`, `ticker.js`, `alert.js`, `pulse.js`) is part of this repository and
carries its licence: MIT, see `LICENSE` at the root.

Fonts are **self-hosted**, fetched by `tools/fetch_fonts.py`, latin and latin-ext subsets only.
A bar's shared wifi is exactly where a third-party font origin costs a second of first paint,
and it is a dependency on a host the venue may block.

Icons and splash screens under `../icons/` and `../splash/` are generated by
`tools/make_icons.py` from the same fonts, so they are covered by the same licence.

Audio assets have their own file, `../audio/LICENCES.md`. All fourteen stings are
synthesised from oscillators and noise by `tools/make_audio.py`, so nothing in this
repository is sampled or downloaded: no broadcast themes, no fight songs, no
commercially released tracks, and nothing to audit before a launch.
